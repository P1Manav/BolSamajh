# BolSamajh

> **Bolo. Samjho.** — Speak to write and act in any app, and talk to any PDF, doc or web page to understand it in your own language.

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

An open-source, Hinglish-first voice companion for the desktop. Dictate in Hinglish, question any document by voice, and command any app — all running locally on your machine.

## 🚧 Under Construction

BolSamajh is being built for the **Bolna × Symphony Voice AI Buildathon**. Full README coming soon.

## Quick Start

```bash
# Clone
git clone https://github.com/your-username/BolSamajh.git
cd BolSamajh

# Setup
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt

# Run
python -m bolsamajh
```
