⚠️ Important Caveats

  • Synthetic audio: The "Synthetic Stress" set uses Edge-TTS synthesized clips with DSP degradations (speed, noise, telephony). This biases WER and is NOT real human speech.
  • Real speech sources: Google FLEURS (Hindi, Gujarati read speech) and HiACC (code-switched Hinglish). These are public datasets, not BolSamajh-specific recordings.
  • Normalization: "Norm WER" applies transliteration normalization via Aksharamukha. "Raw WER" is without normalization. Both are reported for transparency.
  • Human Hinglish recordings: Not yet completed. The recorder tool exists at bolsamajh/benchmark/record_tool.py.

📉 Where BolSamajh Loses

  • Gujarati WER is high (~66-78%) — Whisper models are not optimized for Gujarati script.
  • Code-switched Hinglish remains challenging (~39-51% WER) across all engines.
  • Swift model: Fastest but is an unverified third-party CT2 conversion. Use with caution.
  • Default recommendation: large-v3-turbo balances accuracy (43.5% WER) and speed (573ms), though Swift is faster on synthetic data.
