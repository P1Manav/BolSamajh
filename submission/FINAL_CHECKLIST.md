## 1. Quick Verification & Execution

### One-Command Launch (Desktop Overlay)
```powershell
python -m bolsamajh
```
*HUD overlay docks in system tray with hotkeys: `Alt+Shift+Space` (dictate), `Alt+Shift+D` (load doc), `Alt+Shift+A` (ask doc), `Alt+Shift+C` (voice command), `Escape` (cancel/stop).*

### One-Command Launch (Web UI & Bolna Gateway)
```powershell
python -m uvicorn bolsamajh.web.server:app --port 8000
```
*Access browser interface at `http://localhost:8000` or target OpenAI-compatible voice gateway at `http://localhost:8000/v1`.*

### Run All Unit & Integration Tests (Locally on Clean Venvs)
```powershell
pytest -v -m "not slow and not network" tests/
```
*116 tests passing green across both Python 3.11 and 3.12.*

## 2. Benchmark Reproduction

All benchmark data, real-speech audio manifests, synthetic audio generation, and evaluations are 100% deterministic and script-driven using public, ungated CC-BY-4.0 datasets (Google FLEURS `hi_in`/`gu_in`, HiACC Adult Test Eval):

```powershell
# Step 1: Download public benchmark datasets and generate synthetic test set
python scripts/fetch_benchmark_data.py

# Step 2: Run evaluation across models (large-v3-turbo, medium, whisper-hinglish-swift)
python -m bolsamajh.benchmark.evaluate --models medium large-v3-turbo whisper-hinglish-swift --suite all --device cuda --compute_type int8_float16

# Step 3: Measure hardware latencies and document retrieval speeds
python scripts/measure_hardware.py

# Step 4: Validate documentation tables against generated JSON files
python scripts/generate_readme_tables.py --check
```

## 4. Pending Manual Verification Items

In accordance with our strict honesty policy, features requiring physical hardware transducers, live API keys, physical air-gap disconnection, or telephony trunks are catalogued in [`docs/UNVERIFIED.md`](../docs/UNVERIFIED.md) and detailed step-by-step in [`docs/MANUAL_VERIFICATION.md`](../docs/MANUAL_VERIFICATION.md):

1. **Real Physical Microphone & Keystrokes:** Testing dictation and in-place voice edit with physical speech and human key presses in Notepad, VS Code, and Chrome.
2. **Acoustic Voice Barge-In Feedback:** 10-minute listening test on physical laptop speakers and headphones.
3. **Google Gemini Live API Check:** Running `python scripts/check_gemini.py` with personal `GOOGLE_AI_API_KEY`.
4. **Bolna Cloud Telephony Call:** Live call from Bolna cloud orchestrator via tunnel (requires active Bolna cloud subscription and telephone trunk).
5. **Scanned PDF OCR via Tesseract:** Installing system Tesseract binary with Hindi data (`hin.traineddata`) and testing scanned image PDFs.
6. **Physical Air-Gap Disconnection:** Unplugging Ethernet / turning off Wi-Fi with `.env` offline configuration.
7. **Roman Hinglish Voice Listening Test:** By-ear comparison between `en-IN-NeerjaNeural` and `hi-IN-SwaraNeural`.
8. **90-Second Demo Video Recording:** Recording OBS Studio video following `submission/demo_script.md` and uploading as Unlisted.
9. **Script Re-Runs on Host Hardware:** Re-running `measure_hardware.py`, `measure_bargein.py`, `e2e_dictation_test.py`, `test_offline_mode.py`, and `e2e_doc_qa_test.py`, followed by `python scripts/generate_readme_tables.py`.
